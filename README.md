## Come usare il corso

1. Studia la teoria nella lezione, con formule visualizzate su GitHub tramite LaTeX: per esempio $\log_a(b)=c \iff a^c=b$.
2. Svolgi **un esercizio alla volta**, spiegando il procedimento prima di vedere la correzione.
3. Registra esiti ed errori da ripassare.
4. Non segnare come completato ciò che non è stato effettivamente svolto.
5. Utilizza Python soltanto quando è utile come laboratorio: priorità al ragionamento matematico.

## Formati

- **Markdown + LaTeX**: fonte principale, leggibile e modificabile su GitHub.

- Le formule usano la sintassi supportata da GitHub: $...$ nel testo, $$...$$ per le formule centrate.
