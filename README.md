# Analisi Matematica 1

Corso universitario progressivo di Analisi Matematica 1, con teoria, esercizi guidati, verifica delle risposte e monitoraggio dei progressi.

## Metodo di studio
1. Leggere solo la teoria indispensabile.
2. Risolvere **un esercizio alla volta**, motivando i passaggi.
3. Correggere gli errori e ripetere gli argomenti critici.
4. Registrare il progresso a fine sessione.
5. Usare Python solo come laboratorio quando utile: la matematica e il ragionamento vengono prima.

## Programma
- `00_prerequisiti/`: algebra, potenze, logaritmi, trigonometria e domini
- `01_insiemi_funzioni/`: insiemi, numeri reali, funzioni
- `02_successioni/`: successioni e limiti
- `03_limiti_continuita/`: limiti e continuità
- `04_derivate/`: calcolo differenziale
- `05_studio_funzioni/`: studio completo di funzioni
- `06_integrali/`: calcolo integrale
- `07_serie_numeriche/`: serie e criteri di convergenza
- `08_equazioni_differenziali/`: introduzione alle equazioni differenziali (se nel programma d'esame)
- `09_simulazioni_esame/`: verifiche e temi d'esame

> Il programma è indicativo: sarà adattato al syllabus ufficiale dell'ateneo.
